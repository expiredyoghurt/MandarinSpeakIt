# Recording checklist (Mandarin Say It! v0.2.0)

Record in Admin > Audio (admin.html). One clean take per line, a calm teacher voice, a Singapore-standard Mandarin reading. A clip is only used if it exists; otherwise the browser voice speaks.
Have a second Mandarin-speaking colleague check every clip before pupils hear them. Neutral tones (e.g. 妈妈 māma) matter: the pinyin below is the intended reading.
